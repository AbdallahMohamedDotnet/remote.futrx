# Transcript notes

## Recording

- Duration: 18:23.47
- Video: H.264, 2974×1500, 60 fps
- Audio: AAC, mono, 48 kHz source
- Spoken language: primarily Egyptian Arabic with frequent English product and engineering terms

## Method

The audio was converted locally to mono 16 kHz PCM and transcribed with the multilingual Whisper medium model. Silero voice-activity detection was used to reduce hallucination during pauses and UI interaction. No recording data was sent to an external transcription service.

An initial English-only diagnostic pass was discarded because it misidentified Arabic speech and repeated invented phrases. Only the corrected `application-walkthrough-ar.*` files are retained.

## Accuracy caveat

This is a machine transcript, not a certified verbatim transcript. Egyptian Arabic, code-switching, provider names, model names, and product-specific terms create occasional spelling and segmentation errors. The English [timeline](../timeline.md) is a meaning-preserving chapter translation based on both audio and visible actions; it is not a word-for-word translation.
